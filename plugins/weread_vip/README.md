# 微信读书 VIP 解锁

## 版本说明

- **当前脚本 v6.0.1** — 适配 v6.x 旧版本（无原生签名校验）
- 如需 v10.x 版本，脚本需回退到 v5.1.0（不改签名，仅改显示，10.x 有原生校验无法完全解锁）

## 安装

1. Loon → 配置 → 插件 → 导入 `weread_vip.plugin`
2. 确保已安装并信任 Loon CA 证书
3. 打开微信读书

## 功能

- 会员状态显示为有效（30天）
- 余额/书币显示 99999
- 解除书籍付费墙（可直接阅读付费书）
- 屏蔽更新弹窗（HTTP层面）

## 开关说明

| 开关 | 作用 | 默认 |
|------|------|------|
| 会员卡VIP | 会员摘要/登录/余额 | 开 |
| 解锁阅读 | 书籍信息/付费墙/阅读提示 | 开 |

## 已知限制

### v6.x
- 更新提示可能来自 app 本地硬编码检查，HTTP 层面无法完全屏蔽
- 付费书可阅读但无法实际购买（服务端校验余额）

### v10.x
- 原生 `validateMemberCardSummaryResponse:` 校验签名
- HTTP 修改仅能改 UI 显示，实际会员功能受服务端限制
- 需越狱 hook 原生方法才能完全解锁

## 文件说明

| 文件 | 用途 |
|------|------|
| weread_vip.plugin | Loon 插件配置 |
| weread_vip.js | 核心脚本 |
