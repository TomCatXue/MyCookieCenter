## 🛠️ 核心逆向与技术机制

### 1. C005 混合加解密链路与动态公钥协商
电信权益专区与翼支付前端通信采用了 **C005 一机一密加解密规范**：
1. **动态公钥获取**：每次会话先调用 `https://mapi-h5.bestpay.com.cn/gapi/mapi-gateway/applyLoginFactor`，返回 1024 位 RSA 动态公钥（字段伪装为 `nonce`）；
2. **临时会话密钥**：客户端随机生成 16 位 AES Key；
3. **密钥封包**：使用动态 RSA 公钥以 PKCS#1 v1.5 Padding 方式加密 AES Key，载入请求体的 `key` 字段；
4. **数据加密**：业务参数以 JSON 序列化，通过 AES-128-CBC（IV 全 0、PKCS7 Padding）加密，载入请求体的 `data` 字段；
5. **内容签名**：对原始业务 JSON 执行 MD5 校验计算生成 32 位大写签名，载入请求体的 `sign` 字段；
6. **零依赖移植**：插件内部完整封装了轻量纯 JS 版 RSA、AES 与 MD5 算法套件，无需依赖外部 npm 包或 Node.js 环境，在 Loon 运行时内自给自足。

### 2. 100% 静默捕获与进小程序即时全自动秒领
- **彻底静默无打扰**：进小程序时默认**不弹任何凭据更新弹窗**，仅在后台静默更新 `sessionKey` 与 11 位手机号；
- **进小程序即时秒领**：当检测到用户打开小程序且当天尚未抽奖时，立即利用刚刚生成的最新鲜会话凭证在后台异步启动全套抽奖（做任务 + 抽奖 + 奖品入账），彻底避免凭证过期；
- **抽奖完成战报**：全套抽奖完成后，仅弹出 1 次最终奖品战报汇总，绝不频繁骚扰；
- **日锁定防重**：每日成功自动执行后自动记录日期锁，当天后续反复进入小程序均直接跳过，零多余网络开销。

### 3. 三大抽奖执行与自动领奖流
- **周三会员日抽奖**：
  - 自动调用 `queryDrawActivity` 获取活动状态与奖池；
  - 自动调用 `getLotteryCount` 查询剩余抽奖次数；
  - 循环调用 `lotteryAward` 执行抽奖；
  - 抽中实物或优惠券后，自动调用 `receivePrize` 完成领奖确认。
- **权益商城幸运抽奖**：
  - 自动调用 `freeReceiveLotteryOpportunity` 领取免费抽奖机会；
  - 自动完成分享/打卡内置任务（`completeLotteryTask`）；
  - 查询可用抽奖次数并循环调用 `lotteryReceive` 执行转盘抽奖。

## 📱 使用指南

### 1. 安装插件
在 Loon 中点击「插件」->「右上角加号」-> 粘贴插件订阅地址或添加本地插件：
```text
https://raw.githubusercontent.com/TomCatXue/MyCookieCenter/main/loon/TelecomMemberDraw.plugin
```

### 2. 捕获凭据
1. 确保 Loon 处于开启状态，并且已信任 Loon CA 根证书（用于 MITM 解密）；
2. 打开微信 -> 进入**「中国电信5G会员」**小程序；
3. 点击进入任意权益页面或抽奖专区（如周三会员日或幸运抽奖）；
4. 收到通知提示 `【中国电信 · 会员抽奖凭据更新】`，即代表凭据捕获成功。

### 3. 自动运行
- 默认定时任务规则为每周三上午 09:00（`0 9 * * 3`）；
- 到点自动在后台唤醒执行三大抽奖，抽奖完成后向手机弹出汇总推送报告；
- 如需测试，可在 Loon 插件管理中点击「立即运行」进行单次触发。

## 🚀 进阶：如何彻底突破微信 OAuth 限制，实现 100% 免动手的真·全自动？

### 1. 为什么纯脱机脚本无法凭空刷新微信会话？
微信小程序采用腾讯官方严格的安全鉴权规范：
- 登录必须调用微信客户端底层特权 API `wx.login()`，换取由微信服务器签发的临时授权码 `js_code`；
- `js_code` 的生命周期仅为 5 分钟且为**一次性消费凭据**，翼支付后端拿着它向腾讯服务器换取用户 OpenID 与 SessionKey；
- 翼支付服务端**未提供长期静态 RefreshToken 换票接口**。因此，在没有微信客户端参与的纯脱机服务器/脚本环境下，在数学与密码学上无法凭空伪造新的微信授权 Code。

### 2. 真实会话有效期与心跳保活
- **实测寿命**：电信小程序的 `sessionKey` 在服务端并非几分钟，活跃会话实测可维持数天；
- **心跳保活 (Keep-Alive)**：插件内置了轻量心跳机制，通过定期微量请求刷新服务端 Redis 会话的 TTL，尽可能延长有效周期。

### 3. 全网终极方案：iOS「快捷指令」每周三静默唤醒（零人工介入）
在 iOS / Loon 生态中，最优雅、成熟且完全免人工操作的终极解法，是利用 iOS 系统自带的**「快捷指令自动化」**：

1. 打开 iPhone 自带的 **「快捷指令」App**；
2. 点击底部 **「自动化」** -> 点击右上角 **「+」**（创建个人自动化）；
3. **设置触发条件**：选择「特定时间」-> 设为 **每周三 08:58**（或其他任意合适时间），选择「立即运行」（关闭运行前询问）；
4. **设置执行动作**：
   - 搜索并添加动作 **「打开微信小程序」** -> 选取 **「中国电信5G会员」**；
   - （可选）添加动作 **「等待」** 3 秒；
   - （可选）添加动作 **「返回主屏幕」**；
5. **达成效果**：
   - 每周三上午，iPhone 会在后台自动拉起一次电信小程序；
   - Loon 插件在 **0.1 秒内**捕获到最新鲜、绝对活跃的会话凭据；
   - 触发插件内置的【进小程序即时全自动秒领】链路，后台自动搞定三大抽奖与奖品入账；
   - 手机顶端收到中奖战报推送；
   - **整个过程用户连手机都不用碰一下，实现真正意义上的 100% 全自动！**
