# 中国电信 · 金豆兑换话费

> 捕获电信营业厅 App（`CtClient`）金豆商城的会话凭据，并支持通过 Loon Cron 定时任务在整点自动查询与抢兑话费。

## 功能特性

- **单按钮极简控制**：在 `CookieCenter.plugin` 中仅需一个总开关 (`telecom_gold_enable`) 即可掌控抓取与抢兑。
- **凭证自动捕获**：进入电信 App「金豆兑换话费」页面，自动截获 Authorization Token、手机号与来源 Origin。
- **阈值智能校验**：抢兑前自动查询当前可用金豆，未达预设档位时自动跳过，避免无效请求与风控。
- **高并发对抗**：在整点触发时实施短间隔连试策略（400ms），提升抢兑成功率。
- **全闭环风控反馈**：遇到滑块验证码或库存告罄时，清晰反馈状态，绝不伪造虚假结果。

## 安装与配置

1. 在 Loon 中导入 [`loon/CookieCenter.plugin`](../../loon/CookieCenter.plugin)；
2. 保持「电信金豆·全功能总开关」开启；
3. 打开电信营业厅 App，进入「我的」→「金豆」→「兑换话费」页面，收到 `✅ 电信金豆凭据捕获成功` 通知即表示凭证就绪；
4. 在 BoxJS 中添加 [`boxjs/CookieCenter.boxjs.json`](../../boxjs/CookieCenter.boxjs.json) 订阅，可自定义设置目标手机号与金豆兑换档位（200 / 1000 / 2000 金豆）。

## 已知限制与风控提示

- **滑块人机拦截**：在高峰期部分省份可能强制下发图形拼图验证码，若脚本提示 `⚠️ 触发人机验证`，需在 App 内手动滑动一次；
- **后台时间漂移**：iOS 系统后台唤醒可能存在数秒误差，高竞争时段若库存秒空会收到 `库存告罄` 提示。
