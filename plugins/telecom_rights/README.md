# 中国电信 · 等级权益兑换话费

> 基于电信营业厅 App 真实网关（`wappark.189.cn/jt-sign`），自动截获会话 `sign` 与 `accId`，在 23:59:00 提前唤醒并在 23:59:59.750 毫秒级偷跑直发，实施 4 枪异步阶梯并发突发抢兑每日等级话费券。

---

## 核心架构与技术实现

### 1. 23:59 唤醒 + 250ms 毫秒级偷跑直发
- **定时时序**：Cron 触发时间设为每日 `59 23 * * *`（23:59:00 准点唤醒）；
- **高精度倒计时**：脚本启动后计算至次日 00:00:00 剩余毫秒数，精确挂起等待至 **`23:59:59.750`**；
- **对冲空口延迟**：提前 250ms 扣动扳机直发第一枪，抵消 50~100ms 的空口无线网络传输与系统调度延迟，确保请求在 00:00:00.000 瞬间精准撞线电信服务端；
- **0 点唤醒自适应**：若用户配置为 `0 0 0 * * *`（0点整触发），脚本检测到已过 0 点会自动跳过倒计时，以 0 延迟立即开火。

### 2. 异步阶梯并发突发引擎 (Staggered Parallel Burst)
- **拒绝串行阻塞**：彻底摒弃传统 `await` 串行等待机制，防止前一枪网络挂起或超时拖垮整场；
- **4 枪阶梯并发**：在 750 毫秒黄金窗口内密集发射 4 枪：
  - 第 1 枪：`23:59:59.750`（+0ms 提前偷跑冲击 0 点）；
  - 第 2 枪：`23:59:59.950`（+200ms 准点压哨冲线）；
  - 第 3 枪：`00:00:00.200`（+450ms 极速补刀，穿透前枪 502/超时）；
  - 第 4 枪：`00:00:00.500`（+750ms 二次补刀收尾）。
- **多路并发穿透**：4 枪分别建立独立连接并发射，击中不同后端微服务节点；只要任意一枪中奖或检测到售罄，立即安全收拢，避免无效请求。

### 3. 单枪超时深度优化与 502 自愈
- **超时压缩**：单枪请求超时由 8000ms 缩减至 **4000ms**，绝不在死连接上浪费时间；
- **502 自动识别**：精准捕获电信网关在瞬间过载时返回的 `502 Bad Gateway`，不阻塞其他并发枪次的冲线；
- **总耗时可控**：60s 驻留 + 最长 4s 请求，总执行耗时严格收拢在 65 秒左右，完美契合 `timeout=90` 防御边界。

### 4. 412 瑞数 WAF 绝缘策略
- **逆向发现**：电信网关对携带 App 原生标头（`User-Agent: CtClient;...`）的请求会强制校验全量客户端反爬指纹，脱机请求 100% 触发 412 挑战页；
- **纯净化方案**：
  1. 彻底剔除 `CtClient` 标头，固定使用标准移动端浏览器 User-Agent；
  2. 彻底移除 `Cookie` 请求头，通信全链路仅由 Header 中的 `sign` 与 Body 中 RSA 加密的 `para` 承载，100% 穿透网关与反爬防护。

### 5. 全场景通知闭环（拒绝静默吞没）
- 抢兑结束后，无论结果是**中奖成功**、**名额秒光**、**401 凭证过期**，还是**502 网关过载 / 超时**，100% 必定弹出系统通知，详细汇总各枪战况（如 `0点瞬间网关拥堵 [枪1:超时 | 枪2:502 | 枪3:超时 | 枪4:超时]`），绝不在后台静默吞没。

### 6. 当月中奖深度休眠锁
- 一旦当月成功中奖（或账号当月已领过），自动在本地写入 `telecom_rights_claimed_month` 状态锁；
- 在随后的整月中进入深度休眠，不再发起任何多余网络请求；下月 1 号零点自动解除休眠，循环往复。

## 使用与配置指南

### 1. 开启与捕获凭据
1. 在 Loon 中更新安装最新版 [`loon/CookieCenter.plugin`](../../loon/CookieCenter.plugin)；
2. 确保插件参数 `telecom_rights_enable` 处于开启状态；
3. 打开「中国电信」App -> 底部点击「我」-> 进入「签到」或「等级权益」页面；
4. 收到通知 `✅ 等级权益凭据已锁定: sign: xxxxxxxx...` 即表示捕获成功。

### 2. 定时与抢兑建议
- **凭据新鲜度**：电信的 `sign` 凭据具备时效性（建议在每晚 **23:50 ~ 23:58** 之间顺手打开一次电信 App 等级权益页，保证 0 点处于最高活跃期）；
- **BoxJS 调试**：在 BoxJS 的「中国电信 · 等级权益兑换话费」面板中，可随时点击「查询当月等级权益并执行一次兑换测试」验证链路连通性。
