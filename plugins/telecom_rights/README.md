# 中国电信 · 等级权益兑换话费

> 基于电信营业厅 App 真实网关（`wappark.189.cn/jt-sign`），自动截获会话 sign 与 accId，0 点准时自动抢兑每月等级话费券。

## 功能特性

- **单按钮极简控制**：在 `CookieCenter.plugin` 中仅需一个总开关 (`telecom_rights_enable`)。
- **天然免密与绕过瑞数**：无需脱机破解已失效的手机号密码接口，直接复用手机 App 原生会话与已解密 Cookie。
- **内置原生 RSA 加密**：纯 JS 实现 PKCS#1 v1.5 RSA-1024 加密，与官方 Android/iOS 客户端安全载荷 100% 对齐。
- **智能匹配话费项目**：自动调用 `queryLevelRightInfo` 查询当前用户等级（V1~V7）对应的话费权益 ID，无需手动查找配置。
- **零点自动抢兑**：每天 00:00:00 由 Loon 后台自动唤醒提交。

## 使用方法

1. 更新导入最新版 [`loon/CookieCenter.plugin`](../../loon/CookieCenter.plugin)；
2. 确保「电信权益·全功能总开关」处于开启状态；
3. 打开电信营业厅 App -> 点击「我」-> 进入「签到」或「等级权益」页面，收到 `✅ 等级权益凭据捕获成功` 即表示凭证已锁定；
4. 在 BoxJS 中可随时点击「执行当期权益兑换测试」验证链路。
