# 翼支付 · 权益币秒刷助手

在进入翼支付 App 的“赚钱专区 / 绿色能量”页面瞬间，全自动一键秒收所有权益币、自动签到、秒做所有浏览任务并开启每日宝箱。

---

## 核心功能

- **一键全收**：自动触发底层 `starReceive`，一秒收光树上所有漂浮的权益币与绿色能量球。
- **自动签到**：自动完成每日签到打卡并领取签到奖励。
- **任务秒清**：扫描当月所有“去浏览”、“去查看”任务，直接发送完成指令，**无需在页面停留 15 秒等待**，秒领任务金币。
- **自动开宝箱**：自动领取每日定时宝箱奖励。
- **双重拟态反馈**：
  - 页面顶部优雅的深色玻璃拟态 HUD，实时呈现每一项任务的执行进度。
  - 全部完成后推送 iOS 系统横幅通知。

---

## 为什么这种方式最稳？

翼支付客户端基于阿里/蚂蚁 mPaaS 原生容器开发，网络接口使用了国密 SM2 双向非对称加密。本插件采用**安全无感的前端注入模式**：
- 借助 App 自身已授权的原生 JSBridge（`AlipayJSBridge`）执行；
- **100% 官方正规通道发包**，零风控、零封号风险、不会引发任何“证书错误”或“数据解密失败”。

---

## 使用方法

1. 在 Loon 中通过 URL 添加并开启 `BestpayCoin.plugin`。
2. 打开 **翼支付 App**，进入 **“赚钱专区”** 或 **“绿色能量”** 页面。
3. 页面顶部将自动弹出执行浮窗，2 秒内所有任务全部自动清空！
