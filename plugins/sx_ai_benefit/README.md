# 山西电信·体验AI领福利

每月 1~8 号自动低频随机监控中国电信“体验AI领福利”活动上线状态，发现当月新批次上线时立即弹出高优先级直达通知，提醒抢兑每月限量 1000 份的腾讯视频会员。通知发出后当月彻底休眠，绝不多发一个请求。

---

## 功能特性

- **自动录制**：在电信 APP 首页搜索一次“领福利”，插件自动捕获并存储搜索模板。
- **凭证抓取**：点击进入活动页面自动抓取并存储当月 Cookie 与鉴权参数。
- **无规则随机发包**：每月 1~8 号 08:00~20:00 间，以 25~50 分钟随机间隔探测，每次发包附带 3~18 秒微抖动，彻底消除机器规律特征，零封号风险。
- **单次终结熔断**：一旦检测到新批次上线并发送通知后，当月剩余时间彻底停止探测，不耗电、不跑流量。
- **点击直达**：收到系统通知后，点击通知直接唤起中国电信 APP，直奔活动抢兑。

---

## 使用说明

1. 在 Loon 中通过 URL 导入 `SxAiBenefit.plugin`。
2. 打开中国电信 APP，在首页搜索框输入 **“领福利”** 搜索一次，收到录制成功通知即可。
3. 之后无需任何人工干预，每月 1~8 号后台静默守护，上线即提醒。
