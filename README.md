收拢移动端与自建面板的凭据与任务链路：
Loon 负责无感捕获与即时同步，呆呆面板 / 青龙面板负责脱机定时执行，BoxJS 负责可视化配置。

遇到问题、想加新站点，欢迎提 [Issues](https://github.com/TomCatXue/MyCookieCenter/issues/new)；用着顺手的话，点个 ⭐ 就好。

> `DaiDaiPanel.plugin` 的开关默认开启，可单独关闭不需要的业务；微信读书要先打开「我」的页面，再打开「周二翻牌」页面才能捕获完整凭据。

> **TestFlight 中转**：请求本地应答 `http://tf-relay.test`、多账号索引合并与详情缓存，并每 5 分钟自动续期会话；脚本运行时跟随 [ScriptingApp 原版](https://github.com/ScriptingApp/Community-Scripts) 并自动修补 Loon 兼容层，要求 Loon `>= 3.5.1 (983)`。多账号中转可能违反 Apple 服务条款，账号风险由使用者自行承担。详见 [`scripts/tools/testflight-relay/`](./scripts/tools/testflight-relay/)。

> `camscanner.plugin` 与 `DaiDaiPanel.plugin` 含相同抓取规则，只保留一个即可。

> **命名规范：** 青龙任务名使用 App 名；秒杀任务固定为 `电信秒杀`。Loon 插件名使用简短 App 名，功能细节写入描述。

## 青龙任务

```text
ql repo https://github.com/TomCatXue/MyCookieCenter.git "ql_script" "" "README" "main"
```

| 图标 | 任务 | 功能 | 变量 |
| :-: | :--- | :--- | :---: |
| <img src="icons/weread.png" height="16" /> | **微信读书** | 阅读领卡、翻牌与限免 | `WEREAD_AUTH` |
| <img src="icons/189.png" height="16" /> | **中国电信** | 签到、抽奖与权益领取 | `dxlin` |
| <img src="icons/189.png" height="16" /> | **电信秒杀** | 等级权益抢兑 | `dxlin` |
| <img src="https://github.com/ChinaTelecomOperators/ChinaUnicom/releases/download/Prerelease-Alpha/icon.png" height="16" /> | **中国联通** | 签到、积分与权益 | `chinaUnicom_data` |
| <img src="./icons/linli.png" height="16" /> | **林里** | 取码并签到 | `YYB_SERVER` |
| <img src="./icons/bibisheng.png" height="16" /> | **笔笔省** | 每日领券 | `YYB_SERVER` |
| <img src="./icons/miniso.png" height="16" /> | **名创优品** | 每日签到 | `YYB_SERVER` |
| <img src="./icons/migu.png" height="16" /> | **咪咕音乐** | 签到、听歌与评论领 AI 豆 | `MIGU_AUTH` |

> **变量说明：**
>
> - `dxlin` 格式：`手机号#服务密码#AndroidID[#SessionKey]`，多账号换行或 `&` 分隔；
> - `WEREAD_AUTH`：微信读书抓包 JSON，含 `refreshToken` 永久脱机自愈；
> - `MIGU_AUTH` 格式：`手机号@密码`，多账号换行或 `&` 分隔；默认全开（签到/社区/听歌/评论），仅彩铃设置默认关闭；
> - `YYB_SERVER`：YYB-Go-Enhanced 取码服务，格式 `地址@账号ID`，每行一个账号；林里另需 `LINLI_STORE_ID`、`LINLI_ACTIVITY_ID`，详见 [ql_script/README.md](./ql_script/README.md)。

> **验证状态：** 小程序脚本已通过本地契约与 HTTP mock；真实平台仍需账号实测。
>
> **已归档：** 惠省、海底捞、移动爱家去广告插件，以及中国移动每日任务与移动秒杀青龙脚本已暂停维护并移出公开仓库，源码、图标与逆向证据仅保存在本地 `archive/`（该目录已加入 `.gitignore`，不进公开仓库）。
