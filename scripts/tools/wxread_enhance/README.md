# 微信读书 · 防强更净化

> 专为 8.2.6 等老版本微信读书打造：改写 feature 配置，彻底屏蔽升级弹窗与强更通知，锁定永久免费 AI 听书体验。

## 功能

> 作者：TomCatXue（原水君辅助书收录方案因腾讯云端严格版权过滤已下线，转型专职防强更净化）

- **彻底屏蔽强更**：自动拦截改写 `i.weread.qq.com/feature` 响应体，将 `upgrade`、`notice_type` 与 `notice_msg` 置零。
- **无弹窗打扰**：阻止微信读书在打开时弹出任何升级提示。
- **锁定神仙版本**：让 8.2.6 等具备无限制 VALL-E AI 大模型听书特性的老版本永久稳定运行。

## 使用

1. 在 Loon 中安装 `loon/WeReadEnhance.plugin`
2. 开启 `weread_anti_upgrade` 开关（默认已开启）
3. 打开微信读书 App，静默生效，永不弹窗

## 关于下架好书入架的正解

微信读书云端数据库已对 `shelf/add` 下架图书实行强校验拦截。想将下架好书放入书架并畅享 8.2.6 免费 AI 听书，请使用官方原生通道：

1. 打开网页传书：`https://weread.qq.com/web/upload`
2. 拖入下架书籍的 epub 或 txt 文件
3. 自动生成专属云端图书（`CB_` 开头），多端同步、永不下架、支持 AI 听书。
