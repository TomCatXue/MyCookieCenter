# 青龙面板专属脚本中心 (ql_script)

> 本目录为青龙面板（Qinglong）及各类聚合面板专属脚本仓库，所有脚本严格遵循生产级标准规范：
> 1. **原生内嵌定时与标签**：所有脚本文件头部均显式声明 `@cron`、`@tag` 与 `new Env('...')`，拉取订阅时**自动识别真实定时表达式、任务名称与分类标签**，无需手动配置；
> 2. **极简统一环境变量**：电信全系列脚本统一使用单一主变量 **`dxlin`**（手机号#服务密码#AndroidID），杜绝环境变量碎片化；
> 3. **脱机自愈与高抗风控**：全量内嵌官方 SSO Ticket 动态置换、自适应重签与会话续期机制，永保登录态可用；
> 4. **微信读书极简排版**：统一对齐微信读书单行 Bullet（`• `）极简通知风格，明确回显具体战果、奖品与资产，杜绝模糊占位。

## 📱 微信小程序脚本配置

五个脚本完全独立，统一读取同一个 YYB-Go-Enhanced 服务：

```text
YYB_SERVER = 地址@账号ID
```

- 多账号每行一条；`账号ID` 也可以是 YYB 配置为引用模式的 OpenID。
- 服务启用协议鉴权时，配置 `YYB_API_KEY` 或 `YYB_PROTOCOL_TOKEN`（二选一）。
- 林里、笔笔省、名创优品调用 `POST /wxapp/getCode`（兼容 `/wx/code`），一次性 `wx.login` code 不落盘、不打印。
- `LINLI_STORE_ID` 是企迈门店 ID（例如 `212501`），`LINLI_ACTIVITY_ID` 是签到活动 ID；`wx.login` code 无法推导这两个值，必须从林里签到页请求中抓取。
- 依赖：`requests`；林里、名创优品另需 `pycryptodome`。

本地离线验证：

```bash
python -m py_compile ql_script/linli.py ql_script/bibisheng.py ql_script/miniso.py
```

> **验证状态：** YYB 顶层 `result.code`、请求构造、登录字段、幂等分支和缓存曾在本地契约/HTTP mock 中验证通过；真实平台仍需账号实测。仓库已不再内置测试套件（`.gitignore` 已整体忽略 `tests/`）。
> **林里限制：** `LINLI_STORE_ID` 与 `LINLI_ACTIVITY_ID` 属于业务参数，YYB 只提供登录 code，不能替代。
> **已归档：** 惠省、海底捞、中国移动每日任务（cmcc_all.py）与移动秒杀（cmcc_seckill.py）已暂停维护并移出 `ql_script/`，源码仅保存在本地 `archive/`（该目录已加入 `.gitignore`，不进公开仓库）。

## 📱 中国移动全功能配置（已归档至本地自用）

> **说明**：中国移动日常自动续期、每日聚合与秒杀模块已整合至 Loon 本地插件 / 远程脚本，青龙 Python 脚本已归档至本地 `archive/`，不再上传提交公开仓库。以下文档供本地归档查阅。

### 1. 基础运行环境依赖
确保青龙面板的「依赖管理」->「Python3」已安装以下基础库：
- `requests`
- `pycryptodome`

### 2. 核心环境变量配置 (`CMCC_AUTH`)
在青龙面板「环境变量」中新建变量：
- **变量名称**：**`CMCC_AUTH`**
- **变量取值**：
  直接粘贴抓包或 Loon 插件 `DaiDaiPanel.plugin` 自动同步的完整 JSON：
  ```json
  {"app_token":"JSESSIONID=...; UID=...; Comment=SessionServer-unity; Path=/;HTTPOnly; ticketID=...","phone":"13800000000","province_code":"290","city_code":"029"}
  ```
  *(亦兼容 `app_token#手机号` 简写格式)*
- **多账号配置**：多账号直接**换行**粘贴下一个账号 JSON，或使用 `&` 分隔。
- **可选环境变量**：
  - `CMCC_COC3_TICKET`：AI豆苗养成记 ticket（可选，有则自动喂水升级，无则自动跳过）
  - `CMCC_FEE_SESSION`：移动充值页 session cookie（可选，有则实时查话费余额，无则跳过）

### 3. 业务全开机制（开箱即用）
- **每日聚合主任务**：执行 `python3 cmcc_all.py` **默认直接开启全部日常功能**（签到 + 连签领奖 + AI豆日常任务 + AI豆顶格自动兑换话费券 + 拓展游戏追剧活动 + 周三充值日拼图 + AI豆苗 + 话费查询），无需在青龙命令中拼接任何额外参数。
- **自定义开关控制**：
  - 若想局部调整业务，可在脚本第 40~55 行直接修改 `CONFIG` 字典布尔值（如把 `ENABLE_GOLD` 设为 `False`）。
  - 或通过命令行临时覆盖：`--only-sign`（仅签到）、`--no-gold`（跳过兑话费）、`--dry-run`（只读探测不写）。
- **周三秒杀专用任务**：每周三 08:00 充值日抢 8 折话费券，定时配置为每周三 07:58：
  ```text
  58 7 * * 3  python3 cmcc_all.py --wed-seckill
  ```
- **场次秒杀独立任务**：签到有礼限量大额奖品抢兑，执行 `python3 cmcc_seckill.py --dry-run` 会自动推送下一场抢购时刻与建议定时。

## 📱 中国电信全功能配置指南

### 1. 基础运行环境依赖
确保青龙面板的「依赖管理」->「Python3」已安装以下基础库：
- `requests`
- `pycryptodome`
- `certifi`
- `urllib3`

### 2. 统一环境变量配置（无需配置多余变量）
在青龙面板「环境变量」中新建变量：
- **变量名称**：**`dxlin`**（亦向下兼容 `CHINA_TELECOM_AUTH` / `dxqy` / `TELECOM_WED_AUTH`）
- **变量取值**：统一采用标准三段式格式：`手机号#服务密码#AndroidID`
  ```text
  138****0000#123456#0123456789abcdef
  ```
- **参数说明**：
  1. **手机号**：真实的中国电信手机号（支持携号转网号段）；
  2. **服务密码**：电信 6 位纯数字卡服务密码（拨打 10000 号或在电信 App 安全中心可即时重置）；
  3. **AndroidID**：安卓设备的 16 位硬件标识码（如使用四段式，第 4 段可附加周三专用 SessionKey，但非必需）。
- **多账号配置**：多账号直接**换行**粘贴下一个账号，或使用 `&` 分隔：
  ```text
  138****0000#123456#0123456789abcdef
  139****1111#654321#fedcba9876543210
  ```

## 📚 微信读书配置指南

### 1. 凭据获取方法（只需抓取一次）
1. 打开抓包工具，启动抓包；
2. 打开「微信读书 App」，在「我」页面**退出并重新登录**（或打开任意一本书阅读）；
3. 过滤域名 `i.weread.qq.com`，提取以下 4 个字段：`vid`、`skey`、`refreshToken`、`deviceId`。

### 2. 环境变量配置
在青龙面板「环境变量」中新建变量：
- **变量名称**：**`WEREAD_AUTH`**
- **变量取值**（支持 JSON 或 `#` 分隔）：
  ```json
  {"vid":"12345678","skey":"...","refreshToken":"...","deviceId":"..."}
  ```
  或简写：`vid#skey#refreshToken#deviceId`
> **💡 脱机自愈**：只要包含 `refreshToken` 与 `deviceId`，脚本内置 S-box 引擎在 skey 过期时自动静默换发，永久脱机免重新抓包。
