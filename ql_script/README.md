# 青龙面板专属脚本中心 (ql_script)

> 本目录为青龙面板（Qinglong）及各类聚合面板专属脚本仓库，所有脚本严格遵循生产级标准规范：
> 1. **原生内嵌定时与标签**：所有脚本文件头部均显式声明 `@cron`、`@tag` 与 `new Env('...')`，拉取订阅时**自动识别真实定时表达式、任务名称与分类标签**，无需手动配置；
> 2. **极简统一环境变量**：电信全系列脚本统一使用单一主变量 **`dxlin`**（手机号#服务密码#AndroidID），杜绝环境变量碎片化；
> 3. **脱机自愈与高抗风控**：全量内嵌官方 SSO Ticket 动态置换、自适应重签与会话续期机制，永保登录态可用；
> 4. **微信读书极简排版**：统一对齐微信读书单行 Bullet（`• `）极简通知风格，明确回显具体战果、奖品与资产，杜绝模糊占位。

## 📱 中国电信全功能配置指南

### 1. 基础运行环境依赖
确保青龙面板的「依赖管理」->「Python3」已安装以下基础库：
- `requests`
- `pycryptodome`
- `certifi`
- `urllib3`

### 2. 统一环境变量配置（无需配置多余变量）
在青龙面板「环境变量」中新建变量：
- **变量名称**：**`dxlin`**（亦向下兼容 `CHINA_TELECOM_AUTH` / `dxqy` / `TELECOM_WED_AUTH`）
- **变量取值**：统一采用标准三段式格式：`手机号#服务密码#AndroidID`
  ```text
  17612345678#123456#8a2c4e6f12345678
  ```
- **参数说明**：
  1. **手机号**：真实的中国电信手机号（支持携号转网号段）；
  2. **服务密码**：电信 6 位纯数字卡服务密码（拨打 10000 号或在电信 App 安全中心可即时重置）；
  3. **AndroidID**：安卓设备的 16 位硬件标识码（如使用四段式，第 4 段可附加周三专用 SessionKey，但非必需）。
- **多账号配置**：多账号直接**换行**粘贴下一个账号，或使用 `&` 分隔：
  ```text
  17612345678#123456#8a2c4e6f12345678
  17787654321#654321#b3d5f7a198765432
  ```

## 📶 中国联通配置指南

### 1. 抓包获取凭据
使用手机抓包工具（如 Reqable、Stream、HttpCanary 等），在打开联通 App 并完成登录后，搜索请求头包含 `user-agent` 为 `ChinaUnicom` 的数据包，复制请求头（或完整 query/body）中的核心鉴权串。

### 2. 环境变量配置
在青龙面板「环境变量」中新建变量：
- **变量名称**：**`chinaUnicom_data`**（亦兼容 `unicom_data` / `CHINA_UNICOM_AUTH`）
- **变量取值**：粘贴联通抓包获取的鉴权文本，多账号直接换行粘贴。

## 📚 微信读书配置指南

### 1. 凭据获取方法（只需抓取一次）
1. 打开抓包工具，启动抓包；
2. 打开「微信读书 App」，在「我」页面**退出并重新登录**（或打开任意一本书阅读）；
3. 过滤域名 `i.weread.qq.com`，提取以下 4 个字段：`vid`、`skey`、`refreshToken`、`deviceId`。

### 2. 环境变量配置
在青龙面板「环境变量」中新建变量：
- **变量名称**：**`WEREAD_AUTH`**
- **变量取值**（支持 JSON 或 `#` 分隔）：
  ```json
  {"vid":"12345678","skey":"...","refreshToken":"...","deviceId":"..."}
  ```
  或简写：`vid#skey#refreshToken#deviceId`
> **💡 脱机自愈**：只要包含 `refreshToken` 与 `deviceId`，脚本内置 S-box 引擎在 skey 过期时自动静默换发，永久脱机免重新抓包。
