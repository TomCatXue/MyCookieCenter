# BoxJS 订阅

凭据查看与复制面板，配合 [`CookieCenter.plugin`](../loon/CookieCenter.plugin) 使用。

```text
https://raw.githubusercontent.com/TomCatXue/MyCookieCenter/refs/heads/main/boxjs/CookieCenter.boxjs.json
```

## 应用

| 应用 | 凭据 | 对应青龙变量 |
| :--- | :--- | :--- |
| **微信读书** | App 票据 + 翻牌 Cookie | `WEREAD_AUTH` |
| **中国电信 5G会员** | SessionKey + 手机号 | `dxlin` 第 4 段 |
| **中国电信 权益** | sign / Cookie / accId | `dxlin` |
| **中国电信 山西** | 活动 Cookie | 暂无对应脚本 |
| **扫描全能王** | token / client_id / cs_ept_d | `camscanner_data` |

## 复制与清空

- **复制**：点击数据行 → 「数据查看器」中 value 右侧的复制按钮；或卡片右上角 ⋮ →「复制数据」
- **清空**：卡片右上角 ⋮ →「清除数据」，或数据行右侧 ✕
